# /story-architecture — 故事建築

> **前置條件**：`/story-core` 必須已完成（STORY CLEAR）。  
> 沒有通過 `/story-core` 就進入這裡 → 拒絕執行。

**這個 Skill 做一件事**：確定這部劇的**五個決定命運的時刻**，並建立**資訊建築圖**。

---

## 第一個問題

**說出你的主角的核心創傷（一句話）。**

不是她的背景故事。是：她最深的恐懼是什麼？她用什麼行為模式保護自己不再受那個傷？

這個創傷必須是所有五個時刻的底層邏輯——每個時刻都是這個創傷的一次新的壓力測試。

如果說不出來 → 回到 `/story-core`。沒有清晰的創傷，架構無法成立。

---

## 五個決定命運的時刻

不是「五個 Block」，不是「三幕結構」。是這五個具體的劇情時刻——每個都有清晰的情感交易，每個都對主角的創傷施加了不同方向的壓力：

### 時刻 1：創傷的第一次暴露（Block 1，第 1 集）

觀眾必須在不知道她的背景的情況下，**感受到**她受過傷。
視覺行為，不是台詞解釋。

> 你打算用什麼**具體的視覺行動**暗示她的創傷？

### 時刻 2：第一次以錯誤方式應對創傷（Block 1-2 交界，第 8-12 集）

她主動做了一個選擇，這個選擇是她的創傷在主導的——她以為這是保護自己，但觀眾看出這是在傷害自己。

這是第一個付費牆的設計基礎：觀眾已經投資在她身上，不忍心看她繼續走錯路。

> 她在這裡做的錯誤選擇，跟她的創傷的連結是什麼？

### 時刻 3：最大的表面勝利 / 最深的內在失敗（Block 3，第 35-50 集）

她得到了她「想要」的東西。但觀眾知道這不是她「需要」的東西。她的創傷在這一刻被強化而不是被療癒。

這是全劇情感強度最高的時刻之一——也是讓 PREMIUM 路線作品和量產作品分野的地方。

> 她的「表面勝利」是什麼？這個勝利如何同時強化了她的創傷？

### 時刻 4：無法逆轉的代價（Block 4，第 55-65 集）

她的錯誤方式應對創傷，終於導致了一個她無法撤回的後果。這不是懲罰她，是讓她直面自己一直在迴避的東西。

這是第二個主要付費牆。觀眾在這裡的焦慮感最強——她怎麼從這裡走出去？

> 什麼樣的代價，在這個故事的邏輯裡，是**無法逆轉**的？

### 時刻 5：直面或毀滅（Block 5，第 75-85 集）

她必須選擇：直接面對創傷（允許自己改變），或者被它毀滅。

這個時刻必須讓觀眾感受到**真實的可能性**——她可能選擇毀滅。沒有這個可能性，結局就沒有重量。

> 對這個角色來說，「被創傷毀滅」的具體形式是什麼？

## 資訊建築圖（Information Architecture）

完成五個時刻後，建立這張圖。它是後續所有集數寫作的查詢工具。

**格式**：

```
秘密/資訊節點：[名稱]
觀眾知道的時間點：第 X 集
角色 A 知道的時間點：第 X 集（或「從不知道」）
角色 B 知道的時間點：第 X 集
戲劇性功能：[為什麼這個不對稱很重要]
```

**必須建立的節點**（最少三個，通常五到七個）：
1. 主角的核心秘密（她最不想讓男主知道的事）
2. 男主的核心秘密（他隱藏了什麼，為什麼）
3. 導致付費牆的資訊（第 10 集結尾揭示什麼，讓觀眾不得不繼續）
4. 導致中段反轉的資訊（第 35-50 集揭示什麼，改寫了前面所有事件的意義）

**這張圖一旦建立，後續寫每一集時必須對照它**：
- 這集揭示了哪個節點？
- 揭示後，資訊不對稱的狀態如何改變？
- 下一個需要建立的懸念節點是什麼？

## 裁定系統

### ✅ ARCHITECTURE LOCKED

輸出：
```
主角核心創傷：[一句話]
時刻 1：[第 X 集，視覺行動描述]
時刻 2：[第 X 集，錯誤選擇 + 創傷連結]
時刻 3：[第 X 集，表面勝利 + 內在失敗]
時刻 4：[第 X 集，無法逆轉的代價]
時刻 5：[第 X 集，直面或毀滅的選擇]
資訊建築圖：[列出所有節點]
```

可以進入 `/episode`。

### ⚠️ ARCHITECTURE INCOMPLETE

某個時刻與創傷的連結不清晰，或資訊建築圖有空白節點。  
附上：具體的補全指令。

### ❌ ARCHITECTURE BROKEN

五個時刻使用了相同的情感機制（例如，全部都是「外部威脅」），缺乏情感多樣性。或者時刻 3（表面勝利/內在失敗）不存在——這通常意味著故事沒有 Want vs. Need 的張力，只有障礙和克服，觀眾投資不足。  
回到 `/story-core` 重新確認情感真相。

---

## 不要做的事

- 不要把「架構」等同於「情節摘要」——架構是情感壓力的分佈，不是事件清單
- 不要讓五個時刻都是「熱」的（外部衝突驅動）——時刻 3 和 5 必須是情感內部的
- 不要在資訊建築圖建立之前就開始寫任何集數——你將在第 30 集失去對故事的控制
